Villanelle, before and after

Six real programs from the repository. On the left is the source that compiles today under 0.306. On the right is the same program as it would read if every recommendation in the redesign plan were adopted. The right-hand side is a proposal: no compiler accepts it yet.

How to read the right-hand side

  • Statements without a label run on every history that is still live. A label governs its own line and the block indented under it.
  • Every alternative is named where it is decided. A bare name continues on a path of that name, => exit leaves with the same outcome, and ..group covers a named, closed group.
  • Patterns bind names only. Payload types come from the contract.
  • +, -, / and v[i] compile only when failure is proved impossible, from if tests, where invariants and when conditions.
  • Reading a value is unmarked. mutable x marks a call that may change x, and move x marks the call that ends a resource.
  • A loop can finish with its own outcome through leave, and for walks a collection.
  • Boolean tests are written if. delta is kept for operations with named outcomes.

Choices

Choices in this draft

Kept from today: control, exits, delta, exit, forward, capture, loop and again, bracketed path labels, type-first declarations, auto, mutable, braces and semicolons. The changes below are the ones where a different call would alter the feel most.

  • if for boolean tests. Alternative: keep delta cond { true => a, false => b } as the only form.
  • Reading is unmarked; mutable x and move x are written. Alternative: keep borrow at every call, as today.
  • Method form for collection and trait operations: values.get(key), rule.compare(a, b), order.item. Alternative: keep qualified free calls such as map_get(values, key).
  • Paths are named after their operation by default, as in read.failed. Alternative: always name paths by hand.
  • Function values are written (value) => value >= limit, sharing => with arms. Alternative: a separate spelling for function values.
  • leave ends a loop with an outcome. Alternative: keep one tail loop per body.
  • Unlabelled statements run on live histories only. Alternative: keep today's rule, where code after an exiting arm needs the continuing path's label.
